## 2. Step 2 — the Causal Past Theorem, assembled

### 2.1 The three pieces, as written

**(a) S3 §5, the definition** — `past(A) := { r : FINAL(A, r) } = { r :
un-commit(r) ∉ Env(A) }`, with S3 §4's limit schema: *FINAL(A, r) for every
bounded class A ⟺ W_rev(r) diverges*, and, for finite W_rev, the
constructive converse — the class with budget = cost + 1 on each axis covers
the un-commit (executed; survives the Step 1 fork).

**(b) S5 §2** — `ABS(𝔉, r) :⇔ FINAL(A, r) ∀A ∈ 𝔉`, with family
anti-monotonicity (shrinking 𝔉 preserves ABS; enlarging it can only lose
absoluteness) and the two limits.

**(c) R2's grading table** — causal disconnection is the one kind-level
mechanism: a record behind an event or cosmological horizon is "unrecoverable
by *any* protocol at *any* cost — at the classical causal level this is
impossibility, not suppression"; whereas "a garden-variety record in an
observer's causal past has descendants in that observer's accessible region,
and acting on them to reverse it is causally *permitted* — only
thermodynamically suppressed."

### 2.2 The assembly

Let 𝔅 be a family of declared agent classes.

> **(1)** ⋂_{A∈𝔅} past(A) = ⋂_{A∈𝔅} { r : uc(r) ∉ Env(A) }
> = { r : ∀A∈𝔅, uc(r) ∉ Env(A) } = { r : uc(r) ∉ ⋃_{A∈𝔅} Env(A) }
> **(2)** = { r : C(r) is not finitely purchasable }
> **(3)** = { r : r is causally disconnected }

**(1) is De Morgan.** It is exact, free, and carries no content whatsoever.

**(2) requires COFINALITY.** Both directions need it. ⊇ is S3's constructive
converse — for finite cost there *exists* a covering class — but only if that
covering class is a **member of 𝔅**, with adequate budget on every axis,
adequate carrier access, and the reverse protocol on its menu. ⊆ is the
contrapositive and needs the same. Formally the posit is:

> **COFINALITY.** 𝔅 is cofinal in the T583 capability preorder: for every
> finite performance point p and every finite carrier set K there is A ∈ 𝔅
> whose budget dominates p on every axis, whose carrier access contains K,
> and whose menu contains the reverse protocol.

**(3) requires EXHAUSTIVENESS**, i.e. the two hypotheses of Step 3:
(i) causally connected ⟹ finite cost; (ii) causally disconnected ⟹ no finite
cost suffices. (ii) is R2's kind-level row. (i) is the contrapositive of R2's
degree-level row.

**Corollary (the slogan).** ⋂_{A∈𝔅} past(A) = the causally disconnected set:
*the only class-invariant past is the causal past; every other past is the
complement of somebody's declared context.*

Note the correction to the slogan's usual wording. "Somebody's **budget**" is
too narrow: S3's completion classification absorbs 54 cross-class finality
flips as 49 RESOURCE_BUDGET, 4 ACCESS, and 1 MENU (closure convention;
40/1/1 under closure-free), with **zero unabsorbed either way**. Five of the
flips are not budget at all. The precise claim is *somebody's declared
context*, and that half of the slogan has an executed, convention-independent
witness.

### 2.3 Testing cofinality honestly

**It is not satisfied by the T583 contract's declared class family. It is an
additional posit.** Three independent confirmations:

1. **T583 declares no family.** It declares a context *type* (region, access
   profile, task family, operation menu, resources, cost/error budget,
   horizon) and a native envelope comparison. "The family of all bounded
   classes" is not a T583 object. Its boundary sentence is explicit: T583
   "does not establish a universal capability measure."
2. **S3 §4 disclaims it in writing**, in the sentence that immediately
   qualifies the limit schema the assembly consumes:

   > the "uniform over all bounded classes" clause is witnessed over every
   > *declared* class and secured by the divergence declaration, not by
   > quantification over an infinite class family.

   The assembly needs exactly the quantification S3 says it does not have.
3. **S3's own sweep is provably not cofinal on one axis.** The 10-class
   budget sweep scales energy, time, communication and memory but **holds the
   error bound fixed at 0.01** so the sweep stays a ⊑-chain. Any record whose
   un-commit demands error > 0.01 is FINAL for every class in the declared
   family, for reasons with no causal content at all. Cofinality must
   therefore be stated axis-by-axis, and the error axis has a natural
   ceiling that the other four do not.

**How much rides on it: everything, including the sign.** Take 𝔅 = {A}, a
single class. Then ⋂_A past(A) = past(A) = the complement of one declared
envelope — *somebody's budget*, precisely what the theorem denies. The
theorem and its negation are separated by nothing but the cofinality posit.
It is not a technicality; it is the whole content of step (2).

Cofinality is nonetheless a *cheap and plausible* posit: it says there is no
finite ceiling on capability that is a law of nature short of causal
structure. It is falsifiable in principle (a universe with finite total free
energy accessible to any agent would refute it) and it is not thermodynamic.
It should be **declared and priced**, not smuggled.

## 3. Step 3 — is the theorem functional-independent? (the critical question)

### 3.1 The audit finding under test

A parallel orthodox-physics council audit found that `W_rev` conflates
*forward dissipation* with *reversal cost*: Crooks bounds trajectory-probability
ratios, not the work required to drive a reverse process; consequences are
that a quasistatically-written record (ω → 0) comes out maximally *reversible*
and that ω is protocol-hackable by stirring the bath while writing; the
correct object is the reverse barrier ΔG‡ (Kramers).

**Depth label, stated up front: this finding is not a repository artifact.**
It exists on disk only as a five-line summary bullet in the workspace memory
log (`memory/log.md`, 2026-07-28 science-council entry); the audit text was
never written to the repo, carries no severity label, and proposes no repair.
It is consumed here at **recalled/wave-attributed depth**, as a stated
objection to be tested, never as an established in-repo finding. Nothing
below asserts it is correct — the question is whether the theorem *cares*.

### 3.2 The answer: YES, functional-independent

**Claim.** Let C be *any* cost functional on records satisfying
(i) C(r) is finite whenever r is causally connected to the acting region, and
(ii) C(r) is unbounded or undefined whenever r is causally disconnected.
Then the assembly of §2.2 goes through with C in place of W_rev, unchanged.

**Why.** Walk the three steps and record what each consumes:

| step | what it consumes | does it touch C's internals? |
|---|---|---|
| (1) De Morgan | set algebra only | no — C does not appear |
| (2) cofinality | that Env(A) is "the points A's budget dominates", and that budgets are cofinal | no — only that C(r) is *compared against* a budget |
| (3) dichotomy | hypotheses (i) and (ii) | no — only finiteness, never a value |

Nowhere does the argument use closure-additivity of C, monotonicity of C
along the T586 record order, monotonicity of C along ε, the Crooks two-faces
tie, the Landauer floor, or any thermodynamic content. **C's value is never
used. Only its finiteness is.**

One property *is* used, and it survives substitution: **envelopes grow with
capability** (S3 check (ii)) — needed so that the intersection over a cofinal
subfamily equals the intersection over 𝔅. That is a property of the
feasibility relation (a bigger budget dominates more points), not of C, and
holds for every C.

### 3.3 Substituting ΔG‡ explicitly

Replace W_rev with the Kramers reverse barrier ΔG‡:

- A causally-connected record has a **finite** reverse barrier: the reverse
  path exists, so the barrier is a real number and the Kramers rate is
  nonzero. Hypothesis (i) holds — and it is N8's own absorber-table
  language ("a finite barrier gives a nonzero escape or deletion rate").
- A causally-disconnected record has **no reverse path at all**, so ΔG‡ is
  not infinite — it is **undefined**. Hypothesis (ii)'s "undefined" branch is
  the exact right shape for this case, and arguably a better one than
  W_rev's declared divergence: the fixture had to *declare* an infinite
  number where the physics says there is no number.

**The theorem is unchanged.** The dissipation-vs-barrier error does not touch
it.

### 3.4 The audit's two embarrassments, tested against the theorem

- **The quasistatic record (ω → 0 ⟹ maximally reversible).** This is
  genuinely embarrassing for the *grade*: S3 would rank a carefully,
  slowly-written record as barely committed. Under the theorem it is not
  embarrassing at all — it is **correct**. A quasistatically written record
  *is* easy to undo. The theorem asks only finite-vs-not, and ω → 0 is
  emphatically finite, so the record sits in nobody's class-invariant past.
  The audit attacks the *grading*; the theorem uses only the *dichotomy*.
- **Protocol-hackability of ω.** Stirring the bath while writing inflates ω
  and inflates W_rev. Under the theorem this moves a record's price and moves
  nothing else: an inflated finite number is still finite. Hackability
  destroys the *ordering* of the past — which record is "more past" — and
  leaves the *boundary* of the class-invariant past exactly where it was.

### 4.1 Can an analytic theorem discharge a conjecture?

**Sometimes — and this is one of the cases where it partly can.** The
adjudication turns on what the conjecture was about.

R1's claim sentence is a **compatibility claim**: "Relativity is naturally
compatible with a universe where finality is local, causally bounded, and
observer-indexed rather than global and instant." Compatibility and
consistency claims are settled by constructions, and constructions are
analytic-given-their-definitions. There is no type mismatch in principle: an
analytic exhibit is the *right shape* of evidence for a compatibility
conjecture. A conjecture about the consequences of the program's own
definitions can be discharged by working out those consequences.

**But the exhibit must contain the thing it claims compatibility with, and
this one does not.** CPT contains no Lorentz structure, no metric, no light
cones, no causal structure — "causally disconnected" enters as a declared
predicate. S3 §4 says so about its own fixture in terms this note cannot
improve on:

> The fixture proves nothing about GR: no causal structure is modeled, no
> horizon is derived … The schema above is the honest bridge: it says *if*
> something makes W_rev diverge for every bounded class — as causal
> disconnection would — *then* the grade goes kind-level uniformly, with the
> antecedent supplied by GR, not by this fixture.

So the theorem is a consistency exhibit for R1 **conditional on GR supplying
the antecedent**. It shows the module's finality notion is *compatible with*
relativistic causal structure by assuming that structure. That is genuine —
consistency proofs are allowed to assume the theory they prove consistency
with — but it is weaker than "the six swings earned the founding conjecture."

### 4.2 What the module actually earns, stated precisely

Stripping the imported half, the module's own contribution is one sentence:

> **The class-quantifier collapses to a budget-quantifier.** Quantifying
> finality over all agent classes is the same thing as asking whether the
> reversal is finitely purchasable at all — the "who" drops out and only the
> "how much" remains.

GR — not the module — then says the not-finitely-purchasable set is the
causally disconnected one. This is the *same credit assignment* R2 already
made ("kind-level finality at horizons is classical GR causal structure doing
the work; it is credited to the rival's causal layer"). The frontier lens's
assembly does not move the credit. It changes the **form**: R2 filed it as a
row in a grading table; the assembly files it as a set identity with a
quantifier collapse. That is a real gain in sharpness and a real gain in
quotability. It is not new evidence.
