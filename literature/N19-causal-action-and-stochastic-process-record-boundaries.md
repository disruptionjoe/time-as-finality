# N19: Causal action and stochastic-process record boundaries

## Status

Literature-neighbor note. No Time as Finality claim, roadmap, canon, or
priority movement.

## Why this belongs here

Felix Finster's causal fermion systems and Jacob A. Barandes's
stochastic-quantum program touch different sides of TaF's record/finality
boundary:

- causal action supplies a serious variational selector of physical
  configurations inside a supplied problem;
- stochastic-quantum correspondence supplies a broad representation of
  supplied transition data inside channel/unitary machinery.

Neither currently derives TaF's record formation, stable archive, observer
access, or finality relation.

## Causal fermion systems: what is selected

A causal fermion system supplies a Hilbert space \(\mathcal H\), spin
dimension, operator space \(\mathcal F\), constraints, and a causal action over
positive measures \(\rho\) on \(\mathcal F\). Minimization can select a set of
universal measures, with abstract spacetime

\[
M=\operatorname{supp}\rho.
\]

This is physical configuration selection, not mere representation. It is
nevertheless conditional on the supplied variational problem and generally
does not establish uniqueness.

Primary pointers:

- [Causal Variational Principles on Measure Spaces](https://arxiv.org/abs/0811.2666);
- [Causal Fermion Systems: An Introduction](https://arxiv.org/abs/2411.06450);
- [Continuum Limit Analysis for Curved Spacetimes](https://arxiv.org/abs/2605.30199); and
- [A Geometric Derivation of the Einstein Equations](https://arxiv.org/abs/2607.13871).

## Why this is not yet a record/finality engine

CFS has relevant neighboring constructions:

- [local algebras](https://arxiv.org/abs/2004.00419);
- [future algebras and the ETH comparison](https://arxiv.org/abs/2004.11785);
- [an effective-collapse construction](https://arxiv.org/abs/2405.19254);
- [Fock-space quantum states](https://arxiv.org/abs/2101.10793); and
- [entangled CFS states](https://arxiv.org/abs/2207.13157).

These make CFS a substantial neighbor, but the causal action has not thereby
been shown to select:

```text
one observer boundary
one instrument
one pointer/archive algebra
one access relation
one certification rule
one regional finality condition
```

A local or future algebra constructed after a region and physical
configuration are supplied is not automatically a selected record interface.
An effective collapse equation is not automatically an almost-sure,
finite-time, observer-indexed finality theorem.

## Barandes: exact scope correction

The existing TaF comparator remains useful, but its strongest safe statement
is narrower than the shorthand

```text
stochastic process -> CPTP -> Kraus -> unitary dilation.
```

In the revised
[Stochastic-Quantum Theorem](https://arxiv.org/html/2309.03085v2), the proof
starts from the distinguished initial-time family
\(\Gamma(t\leftarrow0)\), constructs a CPTP map and Stinespring dilation, and
sets the enlarged conditioning-time set to
\(\widetilde{\mathcal T}_0=\{0\}\). The theorem therefore does not by itself
preserve a full multi-conditioning-time process, intervention family, or
trajectory law.

The smallest guard is:

```text
same Gamma(t <- 0)
    can coexist with
different intermediate correlation or held-out intervention
```

This strengthens rather than weakens Barandes as a TaF null model:
Hilbert/channel/unitary structure can be representational, while finality
still requires a physical record and complete temporal/interventional
contract.

## TaF use rule

For a quantum-facing TaF candidate, keep four questions separate:

1. Is the physical process realizable under the declared source law?
2. Is the claimed quantum structure only a nonunique representation or
   dilation of supplied statistics?
3. Which physical interaction forms the record/archive?
4. Which additional condition makes that record final for a declared
   proposition, observer, intervention family, and access boundary?

Do not count narrowing a physical model class as record refinement. Do not
count a base-time stochastic representation as complete history. Do not
count a future/local algebra or decreasing expected variance as a selected
public-finality rule without the missing convergence and access conditions.
